## 1. Approach (summary)
1. **Part A (notebook sections 1-7): TF-IDF + XLM-R ensemble.** Text is normalized (NFKC, zero-width removal, lookalike
   characters, Bangla digits, defanged links, repeated characters, leetspeak). About 12k synthetic training rows are
   generated by code from hand-written templates, plus the 86 rows of `sample.csv` (upweighted x6). Two families are
   trained on the same data: char/word TF-IDF + logistic regression, and `xlm-roberta-base` fine-tuned with one
   multi-task head (label, action, 6 techniques). Part C blends them with weights and threshold chosen by CV.
2. **Part D: LLM labels for uncertain rows.** Every unique test message is labeled zero-shot by OpenAI
   `gpt-4.1-mini` from the official task definitions, priority order and illustrative examples in the problem
   statement. The final rule keeps the ensemble label everywhere except where the ensemble's highest Task A
   probability is below 0.6 (5.4% of test rows); there the LLM label is used (2.7% of labels change). Techniques and
   action are decoded from the ensemble probabilities with the labeling-guide post-rules.
3. **Confidence:** temperature on the ensemble's Task A probabilities, chosen by Brier score on out-of-fold
   predictions; for rows whose label the LLM changed, `clip(1 - confidence, 0.05, 0.6)`.

## 2. Validation
`RepeatedStratifiedKFold(n_splits=5, n_repeats=5, random_state=42)` over the 86 labeled rows, shared by all families
(XLM-R uses the first repeat). Synthetic rows are only ever in training; templates close to a validation row are
removed from that split. Out-of-fold results (composite proxy = (0.40 A + 0.15 B + 0.10 C) / 0.65):

| Model | Proxy | Task A F1 | Task B F1 | Task C F1 |
|---|---|---|---|---|
| TF-IDF + XLM-R blend (Part C, chosen) | 0.921 | 0.952 | 0.844 | 0.916 |
| LLM `gpt-4.1-mini` alone, 86 rows | – | 0.966 | 0.785 | 0.829 |
| Ensemble + LLM on uncertain rows (final rule), 86 rows | – | 0.960 | – | – |

Kaggle: ensemble alone public 0.89153 / private 0.89108; final file public 0.90527 / private 0.90460.

## 4. Reproduction
- **Seeds:** `SEED = 42` (Python, NumPy, torch/CUDA, CV); XLM-R final predictions average seeds 42 and 43; LLM calls use
  temperature 0 and `seed=42`.
- **Environment:** Kaggle notebook, GPU T4, Internet ON, competition data attached; python 3.13 and the Kaggle image's
  libraries (versions are printed by the setup cell); Part D installs `openai` and `python-dotenv`.
- **API key:** put the included `.env` (`OPENAI_API_KEY=...`) in the working directory, or set `OPENAI_API_KEY` as an
  environment variable / Kaggle secret. The key is never written in the notebook.
- **Run order:** Run All. Part A + C take about 1 h on a T4 and write `submission.csv` (ensemble). Part D labels the test
  messages through the API (about 25-30 min, about 29M input / 7M output tokens, about USD 23; results cached in
  `/kaggle/working/llm_cache_*.jsonl`) and overwrites `submission.csv` with the final file.
- **Check:** we re-ran the final cell on the Kaggle outputs of Parts A/C and the cached LLM labels; it reproduces the
  submitted `submission.csv` exactly. LLM output may vary slightly between runs even at temperature 0.
